# Evently starter specification pack

This pack defines the product and the sequence for building it from an empty repository.

## Files
- `PRD.md` — product scope and acceptance criteria
- `architecture.md` — technical architecture and security contract
- `design.md` — UI/UX rules and interaction requirements
- `PHASE_PLAN.md` — from-zero implementation phases and exit gates
- `AGENTS.md` — rules for the coding agent

## Start here
1. Create a new Git repository named `evently`.
2. Put all five Markdown files in the repository root.
3. Open the repository in your coding environment.
4. Ask your coding agent to read all files and perform **Phase 0 only** in `PHASE_PLAN.md`.
5. Review the repository setup and Phase 0 exit gate before asking it to begin Phase 1.

Do not ask the agent to build the whole product in one prompt. Build one verified vertical slice at a time.
